# Controlador Financeiro

Aplicação web para controle financeiro pessoal, com foco em organização de receitas e despesas, acompanhamento de saldo e visão de investimentos por categoria.

## ✨ Funcionalidades

- Cadastro e visualização de lançamentos (receitas e despesas)
- Cálculo de saldo por período (mensal/anual)
- Filtros por data, tipo e categoria
- Dashboard com resumo financeiro
- Área de investimentos (ex.: Renda Fixa, FII, Ações etc.)
- Relatórios e gráficos (ex.: pizza por categoria)
- Importar/Exportar dados (quando aplicável)

---

## 🧰 Tecnologias

- HTML5, CSS3, JavaScript
- VS Code
- Supabase

---

## 🚀 Como executar localmente

### Opção 1 — Abrir direto no navegador
1. Baixe/clone o repositório
2. Abra o arquivo `index.html` no navegador

### Opção 2 — Rodar com Live Server (recomendado)
1. Instale a extensão **Live Server** no VS Code
2. Clique com o botão direito no `index.html`
3. Selecione **Open with Live Server**
